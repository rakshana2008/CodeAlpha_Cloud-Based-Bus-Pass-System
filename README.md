# CodeAlpha_Cloud-Based-Bus-Pass-System
A cloud-based bus pass management system that simplifies online bus pass registration, renewal, verification, and secure digital pass management for students and passengers
## Features
- Online bus ticket booking
- Unique ticket ID generation
- Secure ticket verification
- Fixed route pricing
- Database storage

## Technologies Used
- Python
- Flask
- SQLite
- Cloud Computing

## Installation
Install Flask:

    pip install flask

## Run the Project

    python main.py

## Project Objective
To develop a reliable and scalable bus booking system
that prevents ticket loss, unauthorized access, and
incorrect pricing.
